# Tenant App

Full-Stack Web Application

Core Functionality: Designed and built a multi-tenant application featuring a shared-facility laundry booking system with real-time slot scheduling and user access management.

Architecture & Migration: Transitioning backend data persistence from MongoDB to PostgreSQL to enforce relational data integrity and optimize relational queries across tenancy models.

Cloud & Infrastructure: Cloud-architected for Microsoft Azure (previously hosted with active CI/CD pipelines); repository currently maintained locally for ongoing feature updates.
